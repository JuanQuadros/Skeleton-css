Aprendendo Skeleton

O Skeleton é um framework CSS super leve (~400 linhas), focado em três coisas: grid responsivo, tipografia e componentes básicos (botões, formulários e tabelas).

Cada página abaixo demonstra um tópico, com comentários explicando o que acontece e um desafio no final para você praticar.

Como funciona o Skeleton?

  • Você não escreve CSS para o básico: só usa classes nos elementos.
  • O grid é mobile-first: em telas menores que 550px, as colunas empilham sozinhas.
  • Para personalizar, você cria seu próprio CSS depois do skeleton.min.css.
